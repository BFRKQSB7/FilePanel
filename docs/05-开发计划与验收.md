# 开发计划与验收

**本文件保留初稿的阶段划分与验收场景，作为设计来源，不再承担执行计划或状态维护职责。** 实际任务、依赖、里程碑和进度以唯一索引 [tasks/README.md](../tasks/README.md) 及对应静态 Task Packet 为准，不在本文件逐任务更新状态。下列 P0–P5 是旧设计归类，不是另一套执行 Gate；需求编号对应[需求与范围](01-需求与范围.md)。

## 1. 分阶段交付

| 阶段 | 交付目标 | 对应需求 | 阶段出口 |
| --- | --- | --- | --- |
| P0 契约与工程骨架 | 明确网络边界、用量口径、授权与接口；建立项目和构建 | F01、F07、F12、F17 | 决策记录更新，最小服务可构建运行 |
| P1 单机私有文件闭环 | 管理员初始化、文件上传下载、磁盘保护、持久化 | F01–F03、F18 | 重启后文件和权限保留；异常上传不产生公开文件 |
| P2 公开发布 | 新参考视觉、主页搜索、资源编辑、分享、签名下载与续传 | F04–F08 | 手机和桌面完成上传→发布→访客下载闭环 |
| P3 单机运行保护 | 用量周期、来源限制、动态数据页、域名诊断、NAT 教程 | F09、F10、F15–F18 | 单机额度与网络异常均有真实验证 |
| P4 多节点 | 入网、能力开关、远端存储、出口选择、回退、移动 | F11–F14、F16–F18 | 至少两台实例完成跨节点数据链路验收 |
| P5 发布与维护 | 安装器、个性化包、更新、回滚、卸载和恢复说明 | F08、F19、F20 | 干净机器上验证安装与维护生命周期 |

P1–P3 可形成内部单机预览版，必须标明尚无多节点和完整维护能力。只有完整基线及必要维护检查通过后，才能称为第一版产品交付；手动复制、自动镜像和智能调度不加入上述关键路径。

## 3. 验证方法与边界

协议、用量周期、空间预留和迁移状态机适合以自动测试验证关键不变量；页面排版、真实下载、安装、TLS 与多机路径需实际集成环境。只编译成功不代表浏览器、NAT、证书或多节点下载已通过。

用量验证采用受控小额度和固定大小文件，避免为了测试消耗真实套餐。卸载、空间不足、时间回拨和损坏数据只在隔离目录、虚拟机或专用实例中执行；不覆盖用户正在使用的服务器配置。更新与回滚同时核对旧数据可读性，不能只观察进程是否重新出现。

页面验收按当前新参考的结构和风格对照，不做对外站点内容的像素复制。用户尚未要求页面实现，本次不创建前端演示或启动网站。
