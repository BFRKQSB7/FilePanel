# 页面与视觉规范

**当前视觉依据：2026-10-19 的 FilePanel 工具型界面打磨。本文取代旧版博客参考、蓝紫渐变品牌与大圆角白卡片风格。** 后续页面应沿用本规范和现有 CSS Tokens，不恢复旧截图的视觉语言。

## 1. 设计方向与实现入口

界面面向长期使用的文件与服务器管理：克制、清楚、适中信息密度和桌面工具感。保留文件、用量与状态、使用帮助、设置四个一级入口，设置继续使用六个原有分区；不以视觉优化为由增加业务功能或更改 API。

后台样式统一在 `internal/web/admin.css`，由 Go embed 随二进制发布，通过 `/admin.css` 加载，无构建链和外部字体。`index.html` 不再保存重复的内联样式块；动态页面不能通过 JS 注入另一套控件 CSS。公开页模板位于 `internal/web/public_style.go`，沿用同一基础配色，保留暗色与个性化能力。

不使用品牌、主按钮、进度条的蓝紫渐变；不使用发光、悬浮位移或 scale 动效。图片背景上的均匀遮罩用于保证文字可读性，不属于装饰渐变。管理员提供的图片、Logo 和合法自定义强调色继续生效。

## 2. 公开主页

公开主页 `/` 无需登录，只呈现管理员主动开启主页展示的资源。结构为顶栏、站点横幅、资源标题与搜索、双列资源卡片、页脚；默认不设置推荐分组、标签分类和侧边栏，避免为了复刻博客而增加内容管理功能。

```text
站点名                         资源        搜索  明暗切换

                  居中内容区
┌───────────────────────────────────────────────────┐
│                   站点标题                        │
│                   一句话介绍                      │
└───────────────────────────────────────────────────┘

公开资源                            搜索资源名称或简介
─────────────────────────────────────────────────────
┌────────────────────────┐ ┌────────────────────────┐
│ 封面或中性纯色背景     │ │ 封面或中性纯色背景     │
│ GDPU 小助手            │ │ 示例工具包             │
│ 简介                   │ │ 简介                   │
│ v1.3 · 82.4 MB · 日期  │ │ 1.2 GB · 日期          │
└────────────────────────┘ └────────────────────────┘

站点页脚                                           管理
```

公开资源保留双列布局，使用细边框和小圆角；悬停只改变边框或底色，不位移、不增加悬浮阴影。没有封面时仍保持完整视觉结构，不能出现破图或强制管理员补图；标题最多展示两行，简介最多三行，完整名称在详情页可见。底部保留版本、大小与更新时间，不引入作者头像、阅读量或评论数。

默认按公开资源更新时间倒序，排序规则属于初版建议。资源较多时采用常规分页，初始每页 20 项；搜索仅覆盖公开资源的标题、简介和文件名。空站点显示“暂时没有公开资源”，搜索无结果显示清除关键词入口，网络失败显示重试；不能把加载失败显示成资源数量为零。

## 3. 下载介绍页

`/s/{slug}` 延续同一顶栏、内容宽度、色彩与页脚。页面包含标题、版本、简介、封面或截图、正文、文件名、大小、更新时间、下载按钮与必要的线路选择。点击资源卡片只进入介绍页，点击下载按钮后才申请凭证并开始下载。

未编辑内容时采用文件名、大小和默认“立即下载”即可发布，不强制填写正文或封面。默认模板兼顾纯文字资源与带截图的软件发布，图片限定最大宽度并延迟加载。正文保存 Markdown，渲染时净化危险内容，不提供任意 HTML、JavaScript 或自定义脚本入口。

只有本机时不展示多节点概念。添加可用出口后可显示“自动、本机、IP · 地区”，实际连接地址仍由授权层决定；公开页面不展示节点控制地址、密钥和磁盘路径。出口异常时先尝试允许的回退路径，无法恢复再显示“文件暂时无法下载，请稍后重试”。

下载按钮需有就绪、申请中、开始下载、临时受限、资源不可用、网络失败等状态。请求中避免重复发起授权，受限时展示可重试时间；临时链接过期时提供重新获取入口。介绍页本身在流量保护触发后仍可打开，但不能宣称所有下载器都会自动续传。

## 4. 管理后台

后台入口统一 `/admin`，未认证显示登录界面。仅保留四个一级入口：文件、用量与状态、使用帮助、设置。设置再按站点外观、访问地址、流量保护、节点与线路、账号安全、更新与维护分区。后台沿用公开页面的颜色、圆角和字体，但按操作效率使用桌面表格、手机文件卡片与表单，不强制套用双列资源卡片。

| 页面 | 核心内容 | 常用操作 |
| --- | --- | --- |
| 文件 | 文件名、大小、存储位置、分享/公开状态、任务进度 | 上传、分享、编辑页面、下载、重命名、移动、删除 |
| 用量与状态 | 本机磁盘、用量、下载数与节点最后报告 | 刷新，跳转到保护设置 |
| 使用帮助 | 首次上传与分享步骤、公开范围说明、术语、常见问题 | 回到操作入口、重看开始指引 |
| 设置 | 按用途分区的外观、访问地址、保护、节点、账号与维护 | 保存、检查地址、导入导出、改密、更新 |

上传默认保存到本机，有可用存储节点才显示位置选择。多选与拖入的全部文件进入顺序队列，逐项显示成功或失败，可单独重试失败项。任务进度区分“上传中”“校验中”“完成”“失败”，传输达到 100% 不代表文件已经校验发布。移动操作先显示源与目标、空间检查和对用量的影响，完成后保留原分享地址。

分享弹窗使用原生 dialog，支持 Esc、焦点返回及未保存关闭确认。可选介绍与图片默认收起；保存成功后保留复制链接与查看分享页入口。“分享方式”使用原生下拉框，明确区分“不分享（仅管理员可访问）”“私密分享（仅凭链接访问）”“公开分享（在主页展示）”。已分享文件在弹窗和文件行提供“取消分享”按钮，确认后同时关闭分享页、主页展示和旧下载授权，保留文件与已保存的介绍；取消操作不提交弹窗草稿。删除文件提示影响分享链接和资源内容，确认后才执行。编辑资源页支持内容预览，但预览本身不改变分享状态。

## 5. 数据页与教程反馈

节点以 IP 为主要标题，附“本机”、地区与备注。状态应分为控制在线、存储可达、出口可达、流量受限和数据过期等可理解的提示，不能把心跳在线等同于可下载。数据页显示统计更新时间，刷新后立即呈现加载反馈，重复点击不产生重复请求。

用量文字固定包含“FilePanel 本周期用量”，额度未知时显示“未设置”，不能用无限符号假装已经提供总量保护。高级设置再解释收发口径；对普通使用者直接呈现“达到 950 GB 后暂停公开下载”一类可执行结果。

教程按当前机器事实生成步骤：给出完整 DNS 名称与建议记录，显示解析检查时间与证书状态。无法自动识别 NAT 映射端口或 DNS 托管区时允许补充信息，结果为未知就显示未知。面板能生成反代配置，不代表已替用户部署或修改现有 Web 服务。

## 6. 个性化范围

全站支持站点名称、Logo、站点简介、强调色、主页横幅背景、页面背景、页脚和默认下载按钮文字。单资源支持标题、版本、简介、正文、封面、截图与按钮文字覆盖；它们属于资源内容，不跟随仅含站点品牌的个性化包自动迁移。

个性化包建议为带版本的 `profile.json` 与 `assets/` 目录组成的 ZIP，只包含全站配置和引用素材。导入提供预览与确认，校验图片类型、尺寸、解压大小、路径和兼容版本；成功后统一切换，失败保留旧配置。首版不支持任意 CSS 或脚本，以保持官方模板可维护。

## 8. Typography、间距与层级

使用操作系统字体栈，无外部字体请求。后台正文和按钮 14px、描述 13px、元信息 12px、页面标题 26px（手机 24px）、区块标题 16–20px；字体以 500–650 为主要层级，数据使用等宽数字。手机输入框与 select 为 16px，避免小字号造成输入缩放。

桌面侧栏宽 224px；主区域最大宽 1536px（含内边距），超宽屏仍限制行长；设置表单最大宽 960px，公开页保持 1120px。主要区块间距 24px、表单字段间距 18px、Label/Control/Description 间距 6px。统计使用带分隔线的数据带；设置和帮助使用平面分区，不能每一段说明再包一张白色 Card。

## 9. 基础控件

按钮统一最小高度 44px、横向 Padding 14px、4px 圆角。Primary 为纯 Accent；Secondary（`quiet-btn`）为 Surface 加边框；Ghost 用于退出、行内弱操作等，默认无描边；Danger 仅用于删除、撤销等破坏性操作。Icon Button 为 44×44px，必须有可读 `aria-label` 和提示。所有按钮提供 hover、active、focus-visible、disabled；请求期间使用 `aria-busy` 显示轻量进度符号，禁用态与加载态不可混为一谈。

Input、Textarea、Search、Select 共享边框、背景、字体、行高和 Focus。输入默认 Padding 为 9px 12px、行高 24px，单行高度为 44px；Textarea 允许竖向调整。只读字段使用次级 Surface，错误采用 Danger 边框并配文字，不能仅依赖颜色。原生文件选择按钮和颜色选择框也归入同一规则。Checkbox 保留原生行为和 18px 标记，关联标签形成至少 44px 高的可点击区域。

Select 必须保持原生元素、标签关联和键盘行为，不能换成一组模拟 div。使用 `appearance:none`、右侧 40px 留白和 16px SVG 箭头（距右 12px），与 Input 对齐；所有页面包括移动弹窗、节点、保护、上传存储选择都使用共享规则。Option 指定前景和背景以保证可读性，展开列表的具体外观仍由操作系统/浏览器控制。强制颜色模式恢复原生箭头，不依赖实验性的 `base-select` 或大型组件库。

## 10. Table、Disclosure、Dialog 与反馈

表头使用中性浅底与 12px 次级文字，文件名为 14px 主信息，大小/时间为 13px 次级信息。悬停只改变行底色；文件名、IPv6 与备注允许断行。私有与公开 Badge 共用尺寸和圆角，保留文字区分状态。下载与分享直接显示为 Ghost；移动、重命名、删除和校验码放入“更多”。

“更多”使用原生 details/summary 的行内展开区，不做容易被表格裁切的绝对定位菜单。Enter/Space 打开，Escape 收起并返回 summary；展开后不遮挡相邻行。帮助、上传记录和高级设置也使用统一 Disclosure 高度、箭头和 hover/focus，避免为相同功能实现第二套 Dropdown。

弹窗保留原生 dialog、背景遮罩、可滚动正文和 8px 圆角，宽度不超过 680px/手机屏宽减 32px，高度不超过 90dvh。Tab/Shift+Tab 在当前可见且可用的控件内循环，Escape 和关闭按钮遵守已有未保存确认，关闭后焦点回到触发控件。删除确认和重命名输入继续使用浏览器原生确认框，不改变原有业务语义。

Toast 只在浮层使用阴影，通过 `role=status` 播报；弹窗内 Toast 留在弹窗中，避免被遮罩盖住。错误/成功 Message 有文字、低饱和底色和左侧边框，错误使用 `role=alert`。上传进度与磁盘进度为同一纯 Accent；“发送完成”和“校验保存完成”仍明确区分。空列表、无搜索结果、加载失败继续使用不同说明与恢复操作。

## 11. Responsive 与可访问性

后台 ≤1100px 时侧栏转为四项带文字的横向导航；≤767px 时导航图标上置、设置导航为两列、文件表格转为纵向文件条目、操作区换行。375px 下所有一级入口保留文字，不能压成难以理解的图标栏。768px 保留表格；公开页 ≤760px 时资源和截图单列。

`:focus-visible` 使用同一 Accent 的 2px Outline、3px Offset，不能以去掉 outline 掩盖问题。主要操作至少 44px，所有输入有 Label 或明确可读名；状态同时使用文字；隐藏字段不能被新的 display 规则重新显示。`prefers-reduced-motion:reduce` 下取消过渡、淡入和加载旋转；强制颜色模式保留导航选中轮廓和原生 Select。

验收应覆盖 375、768、1440、2560px 下四个一级页面、六个设置分区、分享与移动弹窗，并检查长文件名、长 IPv6/备注、公开主页和详情页明暗模式。浏览器验证脚本为 `scripts/smoke-admin.cjs`，在隔离本机实例运行，包含布局、键盘与业务 smoke；节点展示夹具只验证渲染，不代表真实远端传输验收。每轮实际结果记录在最终回复，不能把规范中的目标当作已经通过。
