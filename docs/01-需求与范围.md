# 需求与范围

**版本：0.2 草案；日期：2026-10-15；用途：设计基线，不记录执行状态。** 执行状态仅见 [tasks/README.md](../tasks/README.md)。用户明确提出的方向与原聊天助手归纳方案分别记录在[来源与设计决策](06-来源与设计决策.md)。本文件将后者作为初版工作基线，尚未将所有细节视为用户逐项确认。

## 1. 产品定位与使用者

FilePanel 为个人 VPS / NAT VPS 提供文件管理、资源发布和下载分发。主面板在单台机器上独立完成全部基础功能，其他机器安装轻量节点组件后提供额外存储或下载线路。

第一版只设置一个管理员角色。访客无需账号即可浏览管理员公开的资源、访问分享介绍页和下载；管理员通过后台上传文件、编辑页面、维护节点及查看用量。面向不熟悉服务器运维的使用者，常用操作应直接呈现，协议、密钥与调度细节放在系统内部。

## 2. 核心使用流程

1. 在目标机器执行安装命令，获得访问地址与一次性初始化凭证。
2. 首次登录完成密码设置，并填写流量额度；额度未知时明确标记保护能力边界。
3. 拖拽上传文件，默认存储到本机且保持私有。
4. 按需编辑标题、版本、正文、封面与截图，创建稳定分享链接。
5. 按需开启主页展示，使资源出现在无需登录的公开主页。
6. 有域名时在网页检查 DNS 与 HTTPS；有其他机器时通过网页生成入网命令。

以上为目标体验，实际安装地址与命令待发布后提供。当前不得把示例域名用作安装源。

## 4. 文件公开规则

| 状态 | 分享开关 | 主页展示 | 访客行为 |
| --- | --- | --- | --- |
| 私有 | 关闭 | 关闭 | 不出现在列表、搜索或公开介绍页 |
| 分享 | 开启 | 关闭 | 拿到链接可访问，不出现在公开主页 |
| 公开 | 开启 | 开启 | 可访问分享页，也出现在公开主页与搜索 |

开启主页展示时一并开启分享，并在提交前明确显示结果。关闭分享时同时取消主页展示；新的下载授权应立即停止，已签发凭证的失效策略见架构文档。主页不应产生“可见但无权打开”的卡片。

重命名、存储节点迁移和默认线路变化均不改变稳定分享路径。更换主域名会改变 URL 的域名部分，旧域名是否继续访问取决于管理员保留其 DNS、证书和跳转服务，系统不能承诺自动保留。

## 5. 节点与数据保护约束

节点拥有存储和下载两个独立能力，主面板默认两者都有。界面以 IP 为主要显示信息、地区和备注为补充；同一公网 IP 后存在多个 NAT 实例时用端口区分，内部使用稳定 ID 避免 IP 变化造成数据错配。

流量统计覆盖 FilePanel 自己实际收发的数据，不代表服务商账单或整机剩余额度。所有节点分别执行保护，源存储端的出流量与下载出口流量都要计入各自节点；不能仅检查最后一跳。

NAT 主机通过映射端口可以运行面板。节点控制连接在线并不证明文件传输链路可用，更不证明访客能直连下载；第一版要求存在可用映射、受支持的反代或管理员已配置的网络路径。

## 6. 第一版范围外

- 用户注册、多租户、用户组和复杂 ACL。
- WebDAV、FTP、SFTP 服务及对象存储聚合。
- 在线视频、Office 预览、评论、论坛与社交系统。
- 模板市场、多套主题与任意脚本注入。
- 按地区、ASN、权重自动选路的智能 CDN。
- 自动镜像、同步副本、节点故障后自动重建文件。
- 完整服务器监控与强制容器部署。
- 内置通用反向隧道和第三方 DNS 服务商账号管理。

## 7. 非功能目标

轻量首先体现为单机少依赖、流式读写和简单操作流程。内存占用、安装包大小、吞吐与并发上限尚无实测，第一阶段应建立测量基线，再确定最低硬件和性能承诺。

后台使用中文与清晰反馈，长文件名、IPv6、长备注及移动端不能遮挡操作。失败信息说明问题、是否影响原数据及可执行的恢复步骤；不能把“探测成功”写成安装、HTTPS 或真实下载已完成。
