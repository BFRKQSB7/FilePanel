## 3. 设计决策与新增建议

| 决策编号 | 规则 | 来源与状态 | 理由及影响 |
| --- | --- | --- | --- |
| D01 | 主面板含本机 Storage 与 Relay | 用户明确方向 | 单机使用不依赖外部组件 |
| D02 | 统一节点，能力独立开关 | 用户要求及原方案 | 允许大盘节点、下载出口及两者兼具 |
| D03 | 文件与分享/线路分别建模 | 原方案，继续采用 | 迁移与换线路不改变分享路径 |
| D04 | 使用内部稳定节点 ID，界面以 IP 显示 | 本轮补充建议 | IP 会变化，同一 NAT 公网 IP 也可能对应多个实例 |
| D05 | 自动线路跟随管理员默认出口 | 原方案，继续采用 | 保持简单，不引入智能 CDN |
| D06 | 本机回退要求源文件和链路可用 | 本轮补清原方案边界 | 唯一副本离线无法通过换出口恢复 |
| D07 | 无数据路径的 NAT 节点不视作可用存储/下载端 | 本轮补清边界 | 控制心跳不能替代未实现的反向隧道 |
| D08 | 签名默认有效期建议 5 分钟，活动响应与续传分别授权 | 原示例及本轮补充 | 避免大文件到期被误截断，过期新请求仍需拒绝 |
| D09 | 应用收发字节分别统计，策略口径明确 | 原方向及本轮补充 | 多跳均会消耗各自套餐，不能只统计最终出口 |
| D10 | 达到安全线时也限制活动传输 | 本轮补充建议 | 只停止新请求不足以保护剩余额度 |
| D11 | 额度未知时明确总量保护未生效 | 本轮补充建议 | 不能猜测服务商套餐，也不能把空值当成安全无限 |
| D12 | 5% 流量余量、3 个同来源并发 | 原聊天示例，暂作建议 | 需要后续实测与设置，不作为性能或防滥用保证 |
| D13 | 十进制 GB/TB；磁盘可用空间明确 GiB | 本轮补充建议 | 消除原聊天 1000/1024 混用歧义，内部统一字节 |
| D14 | 周期建议默认 UTC，短月取最后一天 | 本轮补充建议 | 周期边界可复现，界面展示实际下次重置时间 |
| D15 | 非零安全余量与在途任务预留须适配1GB小盘，具体契约见 [测试环境](../TEST_ENVIRONMENT.md)；原固定至少1GiB草案已替代 | 2026-10-16 用户要求轻量低配验收后修订 | 防止并发塞满磁盘，同时避免小盘被固定预留值完全禁用 |
| D16 | 移动先校验和切换，再清理源；手动复制复用可恢复任务 | 用户追加多机存储与独立中转需求 | 副本校验后提交，支持手动增减；不引入自动镜像、自动同步或副本重建 |
| D17 | 新参考采用横幅、留白、双列资源卡片 | 用户最新要求及本轮适配 | 借鉴视觉，不引入博客分类与工具站功能 |
| D18 | 个性化包只含全站品牌配置与素材 | 原方向及本轮明确范围 | 单资源内容与正式文件需另行备份 |
| D19 | 常驻服务最小权限，更新操作受限 | 本轮补充建议 | 网页维护不能扩大为任意系统命令能力 |
| D20 | 卸载主面板不联动卸载或删除远端节点 | 用户确认写入 | 远端程序和文件保留，由各节点独立处理 |
| D21 | 主面板离线后停止新下载，活动响应受有效租约和本地保护约束 | 用户确认规则，时限待协议细化 | 失联不删文件，也不能依靠缓存凭证无限提供下载 |
| D22 | 卸载前同一次确认提示远端清单、文件记录和影响 | 用户确认写入 | 不把本机清理误报成整个系统清理；过期或未知数据明确标记 |
| D23 | 彻底卸载后不自动恢复节点和文件管理关系 | 用户确认边界 | 数据库与凭据丢失不能靠同地址重装自动补全 |

以上新增建议已写入草案，便于评审和后续编码；没有因此启动实现或视为不可更改的架构决定。关键契约变化需要同步需求、架构与验收，避免文档互相冲突。

## 4. 开发前需要收敛的事项

| 议题 | 当前建议 | 需要落定的内容 |

| 技术栈 | Go、SQLite、静态资源嵌入 | SQLite 驱动、路由库、前端工具、许可证与版本 |

| NAT 网络 | 使用已有映射/反代，不实现通用反向隧道 | 节点数据端点、证书和可达性验证契约 |
| 节点认证 | 一次性票据换独立凭据 | 协议、凭据轮换、TLS 信任与撤销延迟 |

| 失联与恢复 | 停止新下载，保留文件，原面板恢复需重新验证 | 离线检测时限、活动租约长度、停止延迟与有界重试策略 |
| 用量计费口径 | 默认发送，可选收发合计 | 素材/控制开销范围、持久化误差与超发上限 |
| 默认保护参数 | 保留安全余量并动态检查 | 阈值、并发、限速、重置时区和 UI 提示 |
| 上传与传输 | 首版经面板流式转发 | 超时、重试、取消、哈希和任务恢复契约 |
| 公网与证书 | 自动 ACME 与已有反代并存 | 首版挑战类型、端口权限、证书存储和续期 |
| 更新维护 | 受限维护机制和可信发布清单 | 发布仓库、签名、备份、数据库迁移和回滚 |
| 完整备份 | 运维流程先行 | 是否提供网页备份、远端文件一致性和恢复工具 |
| 视觉实现 | 新参考、单模板、双列卡片 | 具体字号、间距、图标及无图状态的实际渲染 |

这些是下一阶段的设计任务，不要求用户在本轮逐项回答。初稿提供合理工作建议，涉及实际发布、性能或外部服务能力的承诺应在验证后再写入正式使用说明。
