## GOAL

让管理员在唯一官方模板上自定义站点品牌，并安全导出、预览和导入可迁移的个性化包。

## USER VALUE

在网页修改Logo、颜色和横幅；换机器时导入配置包即可恢复全站外观。

## WHY NOW

发布页与素材模型已存在，可以复用而无需搭第二套编辑器；ZIP处理独立隔离，减少下载核心任务体积。

## CONTEXT

FilePanel 不提供多主题或自定义脚本，个性化只覆盖站点名、Logo、简介、强调色、横幅/页面背景、页脚和默认按钮文字。单资源内容可覆盖默认按钮文字，但文件、资源正文与截图、账号、节点凭据、证书和用量不属于站点配置包。页面已按最新MeowVPS参考完成，本任务只绑定全站配置和导入导出，不重做视觉。包采用带schema版本的profile.json和assets/；设置页提供上传、预览、确认后应用，失败保留旧配置。所有素材写入复用空间预算，不能因压缩包导入绕过磁盘保护。本任务只需读取现有配置、模板和素材源码，不读完整PRD或前序任务。

## START REALITY CHECK

任务开始时只核对一次：从 `tasks/README.md` 确认真实依赖均为 DONE，再检查下列源码、API 与 schema 是否存在并与预计基线相符。目录名略有不同可用 `rg --files` 定位等价模块；以真实代码、迁移与 schema 为准，仅当差异影响目标或安全边界时报告 blocker。不要重读前序任务或整套设计文档。

## CONTRACT

1. 配置包只包含全站品牌配置和它引用的素材，不含正式文件、资源内容、账户、节点密钥、TLS私钥或用量。
2. `profile.json` 包含格式版本和逻辑素材引用，导出采用规范相对路径；执行前锁定当前版本，不猜测未来格式兼容。
3. 拒绝绝对路径、`..`、重复规范化条目、符号/硬链接、超限数量/解压大小/压缩比及不允许的文件；以实际解压字节再次检查，不能只信ZIP头。图片按真实内容校验，首版仅PNG/JPEG/WebP，不接收可执行SVG。
4. 导入先在隔离暂存区完成结构/版本/素材/空间验证，再让管理员预览并一次确认；不边解压边覆盖当前素材。
5. 应用采用事务加版本化素材目录或等价原子切换；失败与重启要么旧配置完整可用，要么新配置完整可用，不能产生混合引用。
6. 默认设置不覆盖单资源明确设置；无自定义Logo或背景仍正常显示。删除旧素材前确认没有活动引用。
7. 不新增任意HTML、CSS、JS、主题市场或外部图片热链依赖。
