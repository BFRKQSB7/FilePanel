## GOAL

提供面板/节点在 Alpine/OpenRC、Debian/systemd 与 Ubuntu 24.04 LTS/systemd 上的一条命令安装、最小权限运行和严格仅清理本机的卸载闭环。

## USER VALUE

用户安装后主要在网页管理；卸载一次确认便明确清理本机，知道远端仍留下什么。

## WHY NOW

真实面板与节点二进制接口已存在，安装器可以绑定实际产物；无需依赖T06移动结果，避免人为串行。

## CONTEXT

首版仅支持 Alpine/OpenRC、Debian/systemd 与 Ubuntu 24.04 LTS/systemd、amd64/arm64；优先验证 Alpine 3.23、Debian 13 与 Ubuntu 24.04 LTS，模板版本按结果标注，不扩展其他发行版。运行不依赖Docker、MySQL、Redis、Node.js。拟定布局：/usr/local/bin/filepanel、/etc/filepanel、/var/lib/filepanel、/var/cache/filepanel；Debian/Ubuntu可用journald，Alpine使用受限日志路径与轮转，均限制保留。脚本不默认存在Bash/GNU工具；二进制优先无CGO外部运行库依赖，分别验证musl/glibc环境实际可执行。目录可配置但所有权必须可验证。常驻服务以专用用户运行，root仅用于固定安装/卸载和受限维护动作。主面板两种卸载都不联动远端；purge会丢失主面板索引/凭据，重装不自动找回旧节点。T08随后接入可信发布/网页更新，本任务先用本地可信fixture完成全流程，不伪造在线安装地址。

## CONTRACT

1. 安装器检测平台/架构/端口，使用受信下载清单校验产物再落地；支持明确的离线/本地release来源测试，不提供example.com假命令。在线发布源未配置时说明限制，不临时使用陌生源。
2. 创建专用运行用户、严格权限、安装清单，以及按实际平台选择的OpenRC服务脚本或systemd单元；各平台都支持启停、开机自启、受限日志与供T08调用的固定维护动作。不要求Alpine安装systemd，不把容器中不可用的init当作服务已启动；失败返回非零、说明实际阶段，不能在未启动或未入网时打印成功。
3. 重复安装不重置密码/节点身份、不覆盖数据库，安装冲突安全失败；输出真实候选入口及初始化方式，令牌不得进入公共日志。
4. 维护权限只允许固定校验后的二进制/服务/备份操作，不开放任意shell、参数注入或任意路径覆盖；低端口使用最小必要capability或管理员已有反代。
5. `uninstall`删除本机程序/服务并保留数据与必要凭据；`uninstall --purge`删除本实例拥有的数据/配置/素材/日志/缓存。均只执行一次明确确认，取消无副作用。
6. 递归清理前解析规范绝对路径并验证安装清单/所有权，拒绝根目录、共享目录、链接逃逸与清单外目录；自定义数据盘不能整盘删除。
7. 删除主面板数据库前展示远端IP/端口、备注、最后在线时间、关联文件数量/记录大小；过期标过期，数据库不可读标未知，不冒充实时远端扫描。
8. 确认和最终结果明确：只卸载本机，远端程序/文件保留，分享入口不可用，purge后重装不会自动恢复管理关系。不得发送任何远端卸载/删文件命令。
9. 节点机独立卸载仅作用于该节点实例，不能波及主面板或其他节点；主面板停止后节点继续遵守失联租约规则。
