    使用帮助

    一台服务器即可使用；域名和额外节点均可稍后配置。

    上传并分享文件

    1. 在“文件”页选择或拖入文件，等待结果显示“已完成”。文件默认私有。
    2. 点击文件旁的“分享”，选择“私密分享（仅凭链接访问）”或“公开分享（在主页展示）”。标题、版本、介绍和图片均可留空。
    3. 点击“保存分享设置”，然后复制分享链接发给他人。
    4. 私密分享不在主页展示。已分享文件可点击“取消分享”，确认后原链接失效，文件仍保留。
    5. 使用“分享状态”筛选已分享文件，勾选后可批量转私密、转公开或取消分享。分享窗口可选择下载页面模板，并指定可用的下载 / 中转出口。
    6. “更多 → 存储与副本”支持复制并保留原件、移除额外副本；只保留主位置就是单份存储。存储与下载出口分别配置，地区下载按钮表示实际流量出口。

    不分享：仅管理员访问。私密分享：仅凭链接访问下载页面，不在主页展示。公开分享：在主页展示，也可通过链接访问。

    让访客从外网访问

    分享链接使用站点访问地址。若链接含 localhost、127.0.0.1 或内网地址，其他网络的访客通常无法打开。

    在“设置 → 访问地址”选择你的情况，填写服务商提供的公网地址和端口，再按检查结果处理。当前入口能访问，不代表其他网络也能访问。

    常见问题与术语

    磁盘容量和下载流量有什么区别？

    磁盘是存放文件的空间；流量是上传和下载传输的数据量。FilePanel 只统计自身传输，不等于整机流量或服务商账单。请按套餐额度配置流量保护。

    校验码、Markdown、节点是什么？

    SHA-256 是文件校验码，用于比对下载是否完整，普通下载无需输入。Markdown 是文字排版语法，不熟悉时直接写普通文字即可。节点是额外的服务器，可用于存放文件或提供下载线路；只有一台服务器时不需要添加。

    DNS、NAT、HTTPS 和证书是什么？

    DNS 把域名指向服务器地址。NAT 端口映射把外部端口转到服务器内部端口。HTTPS 加密浏览器与服务器之间的连接，证书用于验证服务器身份。无法确定公网地址或映射端口时，请查看服务商控制台，不要照抄内网网卡地址。

    下载受限或文件暂不可用怎么办？

    先查看“用量与状态”的保护提示和“设置 → 节点与线路”的连接状态。额度用尽后需等待下一周期，或按真实套餐修正额度；请勿为了排错随意关闭保护。网络失败时可重新打开分享页获取下载地址。

    如何备份、更新或找回密码？

    外观配置包只保存站点外观，不是整站备份。整站备份、恢复和密码问题需要服务器管理员处理；不要删除数据目录重新初始化。程序更新的前置条件和备份说明在“设置 → 更新与维护”。

    设置

    按用途选择分区；切换分区会保留未保存的输入，刷新或关闭页面前请保存。
