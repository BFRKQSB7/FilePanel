QUICK START

使用教程

完成初始化后即可在本机管理私有文件。

开始使用

所有操作通过当前面板完成，文件不会自动公开。

  1. 选择“文件”，点击上传或将文件拖放到上传区域；文件默认私有。
  2. 上传完成后可下载、重命名或删除；下载内容会使用 SHA-256 校验值标识。
  3. 使用“设置”修改管理员密码；修改后所有会话立即失效。
  4. 登录凭据只保存在本机数据目录，请妥善保管并定期备份该目录。

在文件行点“分享”可编辑介绍并开启公开页；访客主页是站点根路径 /，管理后台位于 /admin。在下方可配置访问地址、检查 DNS / NAT，并在条件满足时申请 HTTPS 证书。
